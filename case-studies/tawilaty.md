# Tawilaty — customizable school-furniture storefront

**Source:** Private repository `zakibox/tawilaty`  
**Technology:** Next.js, React, TypeScript, server-side API routes.

## Product and system
A B2B storefront prototype for configurable school furniture, with a product catalog, material/color/dimension selection, quantity pricing, shopping cart, WhatsApp quote/order flow, and bilingual French/Arabic interfaces. The application also includes a server-side route for a product-advice chatbot.

## Architecture highlights
- Next.js App Router pages and server-side API endpoints.
- Reusable product customizer components and catalog/pricing utilities.
- Shared cart state and locale-dependent UI.
- An AI assistant endpoint keeping the API key server-side.

## Scope and limits
This is a **prototype/starter**, not a verified production-commerce deployment. The CMI checkout route explicitly uses demo mode and requires the merchant integration kit, server-side order persistence, payment signature and confirmation logic before accepting real payments.
