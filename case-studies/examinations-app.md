# University examinations management — collaborative project

**Repository:** [HamzaEzziymy/examensApp](https://github.com/HamzaEzziymy/examensApp) (team-owned, public)  
**Technology:** Laravel 12, React, Inertia.js, Tailwind CSS, relational database.

## Product and system
A university academic and examination-management application. The repository includes modules/controllers covering academic structure, students, examination sessions, room allocation, invigilation, attendance, grading, results, commissions and deliberations.

## My role
**Collaborative system conception and architectural/design-pattern work**, plus application contributions visible in Git history. [View commits attributed to zakibox](https://github.com/HamzaEzziymy/examensApp/commits?author=zakibox).

Examples of attributed changes include academic-level filtering by degree track, changes involving academic-year/level data, and an Inertia rendering adjustment. These are examples of contributions, not a claim to have built every module.
